# GYM COMMAND

Mobile-first workout log built with Expo + React Native + TypeScript.

## Start

1. Install Node.js LTS.
2. In this folder run `npm install`.
3. Run `npx expo start`.
4. Install **Expo Go** on your phone and scan the QR code (or use an Android emulator).

## Current features

- Industrial dark UI: charcoal, steel grey and warning red.
- Dashboard with workout count and logged sets.
- Log a workout with exercise name, sets, reps and weight.
- Workout history saved locally on the device.
- No account or cloud sync yet.
